# 1. Project Overview

**Project Name:** Student Task Manager

**Objective:** Build a simple React application where students can add tasks, view their task list, mark tasks as completed, and delete tasks.

This project will help students practice the React topics they learned last week, including components, JSX, conditional rendering, props, events, component composition, and error handling.

---

# 2. Required Features

Students must implement the following features:

1. **Display Tasks:** Show a list of tasks with their titles and status.
2. **Add New Task:** Create a form with a task input field and an Add Task button.
3. **Complete a Task:** Add a checkbox or button to mark a task as completed.
4. **Delete a Task:** Allow users to remove a task from the list.
5. **Conditional Rendering:** Show "No tasks available" when the task list is empty.
6. **Task Statistics:** Display the total number of tasks and completed tasks.
7. **Form Validation:** Do not allow users to submit an empty task

---

# 3. Bonus Tasks (Optional)

Students who finish early can implement any of these:

* Filter tasks by All, Completed, and Pending.
* Display a confirmation message before deleting a task.
* Show a friendly fallback UI if the task list cannot be displayed.
* Create a reusable `Card` component using the `children` prop.
* Add a task counter showing how many tasks are remaining.
